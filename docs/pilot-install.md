# Install AthleteOS (pilot)

## iPhone (Safari)

1. Open AthleteOS in Safari.
2. Tap Share.
3. Tap Add to Home Screen.
4. Tap Add.
5. Open AthleteOS from the home screen.

## Android (Chrome)

1. Open AthleteOS in Chrome.
2. Select Install AthleteOS or Add to Home Screen.
3. Confirm.
4. Open AthleteOS from the home screen.

AthleteOS needs a network connection for sign-in, workspaces, and conversation.
