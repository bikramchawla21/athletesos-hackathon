# AthleteOS Thin MVP Specification

## Core hypothesis

Can AthleteOS understand an athlete through an adaptive conversation well enough that the athlete recognizes the resulting pattern and finds the priority personally meaningful?

## Primary user loop

Welcome → Discovery conversation → Reflection → Evidence → Pattern → Shared priority

## Required capabilities

- Typing-first conversation
- Context-aware variable follow-up questions
- Correction and understanding checks
- Conversation completion control
- Structured observation extraction
- Evidence tied to athlete statements
- One highest-leverage working pattern
- One shared priority and up to three focus areas

## Explicitly out of scope

- Voice input
- Authentication
- Wearables
- Video analysis
- Coach dashboard
- Payments
- Long-term database memory
- Medical or psychological diagnosis

## Success criterion

After viewing the reflection, the athlete says some version of: **“That is exactly what has been happening.”**
